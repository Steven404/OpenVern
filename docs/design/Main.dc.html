Agent loop and tool calls

How should the agent loop handle tool calls? I want it simple: send messages, run any tools the model asks for, feed the results back, repeat.
[APPNAME]

That shape is right. Keep the loop as one function that only stops when the model's reply contains no tool calls.

read_file src/agent/loop.ts 0.2s 
while (true) {
  const reply = await model.send(messages)
  messages.push(reply)
  if (!reply.toolCalls.length) break
  for (const call of reply.toolCalls) {
    messages.push(await tools.run(call))
  }
}

Two guards are worth adding early: a maximum number of turns, so a confused model can't spin forever, and a confirmation step before any tool that writes to disk.
