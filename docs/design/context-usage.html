Counter

A 40px ghost button like its neighbours, set in mono because it is a count. Only the used figure changes colour.

Panel

352px wide, on the Dusk surface. The percentage and the bar carry the warning; the figures below never change colour.

Rules

Context used
The prompt and completion tokens of the latest reply: what the chat already fills of the model's window, and what the next turn builds on.
Total tokens used
Input plus output of every request in the chat, tool-call round trips included, so it outgrows the context figure quickly. Total cost sums the same requests.
Number format
Exact under 1,000, then thousands to one decimal (97.3k), dropping a trailing .0 (12k). Limits round to whole units (256k, 1M). Exact counts sit in the tooltip.
Thresholds
Moonlit below 80%, gable brick from 80%, signal coral from 95%. The percentage always states the level, so colour is never the only cue. Above 0 but under 1% reads <1%.
Opening
A popover aligned to the counter's right edge, 8px below it. Esc or a click outside closes it and focus returns to the counter.
Updating
The figures change when a reply finishes, not while it streams. Before the first reply the counter reads 0 / 256k and Last activity equals Created.
